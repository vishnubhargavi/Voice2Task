# 🎙️ Voice2Task

Voice2Task is a voice-powered task management application that converts spoken instructions into organized tasks.

Instead of manually typing every task, users can use their voice to create and manage tasks quickly and naturally.

## 🚀 Features

- 🎤 Voice-based task creation
- 🤖 AI-powered voice processing
- 📝 Converts spoken instructions into structured tasks
- 🗄️ Database support for storing tasks
- ⚡ FastAPI backend
- 🔌 API-based architecture
- 📋 Structured request and response validation

## 🛠️ Tech Stack

- **Python**
- **FastAPI**
- **AI / Natural Language Processing**
- **SQLAlchemy**
- **Pydantic**
- **SQLite / Database**
- **Uvicorn**
